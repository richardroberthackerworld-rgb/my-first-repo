# Samples

Generated output, committed so the pipeline's behaviour is visible without
running anything.

- `7hand-sample.pdf` — two A4 pages, 1,254 letters from 159 embedded shapes,
  141 KB. Built with the **demo style**, which is a serif typeface pushed
  through the real pipeline. It exercises layout, drift and PDF export; it is
  **not handwriting and will not fool anyone**.

Regenerate from `app.html`: load the demo style, paste text, Download PDF.
