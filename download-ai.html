Quick Start

// 1. Include the engine <script src="7by-ai-engine.js"></script> // 2. Create an instance const engine = new SevenByEngine({ onProgress: (percent, message) => console.log(percent, message) }); // 3. Decode audio const ctx = new AudioContext(); const response = await fetch('song.mp3'); const arrayBuffer = await response.arrayBuffer(); const audioBuffer = await ctx.decodeAudioData(arrayBuffer); // 4. Remove vocals const { vocals, instrumental } = await engine.separate(audioBuffer, { mode: '2stem' }); // 5. Encode to WAV and download const blob = engine.encodeWav(instrumental); const url = URL.createObjectURL(blob);

API Reference

MethodReturnsDescription
new SevenByEngine(opts)SevenByEngineCreate engine. opts.onProgress(percent, msg) callback is optional.
.separate(buffer, {mode})Promise<Object>mode:'2stem' → {vocals, instrumental}. mode:'4stem' → {vocals, instrumental, drums, bass, other}
.cut(buffer, startSec, endSec)Promise<AudioBuffer>Trim audio between two timestamps in seconds.
.join(buffers[], gapSec)Promise<AudioBuffer>Concatenate AudioBuffer array with silence gap between each.
.removeNoise(buffer, strength)Promise<AudioBuffer>Noise reduction. strength 0–1 (0.1=gentle, 0.9=aggressive).
.pitchShift(buffer, semitones)Promise<AudioBuffer>Shift pitch ±12 semitones. Positive = up, negative = down.
.encodeWav(buffer)BlobEncode AudioBuffer to 16-bit PCM WAV Blob. No dependencies.
