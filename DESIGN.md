# Design System — 7By.in

## Product Context
- **What this is:** Free AI-powered audio and media processing tools platform
- **Who it's for:** Musicians, podcasters, content creators, developers, and everyday users who need quick audio/image processing without paid software
- **Space/industry:** Online tools / AI SaaS — peers include remove.bg, vocalremover.org, noise.ai
- **Project type:** Web app with marketing landing page + blog
- **Founder/CEO:** Shirandasu Sandeep

## Aesthetic Direction
- **Direction:** Dark Glassmorphism + Neon Waveform
- **Decoration level:** Expressive — animated waveform hero, glowing card halos, grain texture on glass surfaces
- **Mood:** Premium and powerful. The tools should feel like studio-grade software running in a browser, not a free web widget. Dark-only — the aesthetic IS the brand.
- **Memorable thing:** "The dark tools site where everything glows when you touch it."

## Typography
- **Display/Hero:** Outfit 800 — ultra-bold, tight tracking (-3px at large sizes), strong authority
- **Body:** Outfit 400/500 — same family reduces load overhead, excellent legibility at 14-18px
- **UI/Labels:** JetBrains Mono — signals precision/tech, used for tags, badges, tool metadata, format labels
- **Data/Tables:** JetBrains Mono (tabular-nums) — consistent column widths for audio metadata
- **Code:** JetBrains Mono
- **Loading:** Google Fonts CDN — `family=Outfit:wght@300;400;500;600;700;800&family=JetBrains+Mono:wght@400;500`
- **Scale:**
  - Hero: 96px / 800 / -3px tracking / 1.0 line-height
  - H1: 52px / 800 / -1.5px
  - H2: 32px / 800 / -1px
  - H3: 22px / 700 / -0.5px
  - Body: 16px / 400 / 1.6
  - Small: 14px / 400
  - Mono label: 11-13px / 400-500 / +2-3px tracking / uppercase

## Color
- **Approach:** Expressive — color as primary design tool, neon on dark
- **Background:** `#09090F` — deep slate, almost black with a slight blue shift
- **Surface:** `#0F0F1A` — card and panel backgrounds
- **Surface 2:** `#141428` — nested surfaces, waveform demo backgrounds
- **Primary (Cyan):** `#00D4FF` — audio tools, primary CTAs, active states, progress bars
- **Secondary (Magenta):** `#FF006E` — video tools, secondary actions, accent highlights
- **Tertiary (Amber):** `#FFB800` — image tools, AdSense slot indicators, warning states
- **Text Primary:** `#F0F0F8` — main content
- **Text Muted:** `rgba(240,240,248,0.5)` — secondary text, descriptions
- **Text Dim:** `rgba(240,240,248,0.3)` — timestamps, metadata, placeholders
- **Border:** `rgba(255,255,255,0.08)` — default
- **Border Bright:** `rgba(255,255,255,0.15)` — hover states
- **Semantic:** success `#00C896`, warning `#FFB800`, error `#FF4444`, info `#00D4FF`
- **Tool category glow system:**
  - Audio tools: `box-shadow: 0 0 0 1px rgba(0,212,255,0.3), 0 16px 40px rgba(0,212,255,0.12)`
  - Video tools: `box-shadow: 0 0 0 1px rgba(255,0,110,0.3), 0 16px 40px rgba(255,0,110,0.12)`
  - Image tools: `box-shadow: 0 0 0 1px rgba(255,184,0,0.3), 0 16px 40px rgba(255,184,0,0.12)`
- **Dark mode:** Dark-only. No light mode toggle. The dark aesthetic is the brand identity.

## Spacing
- **Base unit:** 8px
- **Density:** Comfortable — enough whitespace to breathe, enough density for AdSense slots
- **Scale:** 2xs(4) xs(8) sm(12) md(16) lg(24) xl(32) 2xl(48) 3xl(64) 4xl(80)
- **Section padding:** 80px vertical, 32px horizontal (mobile: 60px / 16px)

## Layout
- **Approach:** Hybrid — 12-column strict grid for tool pages (AdSense placement friendly), creative editorial for hero and blog
- **Grid:** 12 columns, 24px gutter
- **Max content width:** 1280px
- **Nav height:** 64px fixed
- **Border radius:** sm(6px) md(10px) lg(12px) xl(20px) pill(9999px)
- **Tool cards:** `minmax(300px, 1fr)` auto-fill grid, 20px gap
- **Blog cards:** `minmax(300px, 1fr)` auto-fill grid, 24px gap

## Google AdSense — Placement Strategy
Four ad slots per page for maximum revenue while preserving UX:

1. **Below-hero Leaderboard (728×90)** — highest CTR position, above the fold after the hero CTA
2. **Tool page right sidebar Rectangle (300×250)** — standard "golden" AdSense unit, appears while user waits for processing
3. **In-content Leaderboard (728×90)** — between tools section and blog section
4. **Pre-footer Leaderboard (728×90)** — catches users scrolling to the bottom

AdSense approval checklist met by design:
- Sufficient original content (tool descriptions + blog)
- Clear navigation and site structure
- Privacy policy and terms of service pages linked in footer
- No deceptive ad placement (dashed border + label on placeholder slots)
- Mobile responsive layout (ads resize correctly)

## Motion
- **Approach:** Expressive — scroll-driven entrance animations, waveform hero, glowing pulse
- **Easing:** enter(`ease`) exit(`ease-in`) move(`ease-in-out`)
- **Duration:** micro(100ms) short(200ms) medium(300ms) long(500ms)
- **Key animations:**
  - Hero waveform: canvas-based, mouse-reactive, 4 layered sine waves in cyan/magenta
  - Tool cards: `fadeUp` on scroll intersection (opacity 0→1, translateY 24px→0, 500ms)
  - Card hover: `translateY(-4px)` + category glow (300ms)
  - Nav CTA hover: `translateY(-1px)` (200ms)
  - Waveform bars: randomized height static bars, color-coded by stem type
  - Dot badge: `pulse` keyframe (scale + opacity, 2s infinite)

## Component Patterns
- **Nav:** Fixed, `backdrop-filter: blur(20px)`, dark glass, 64px height
- **Hero badge:** Mono font, cyan border, animated pulse dot, pill shape
- **Tool cards:** Glass surface + border, category icon in tinted square, category label in mono, glow on hover
- **Upload area:** Dashed cyan border, hover intensifies, format badges in mono
- **Waveform bars:** Flex row, randomized heights, color by stem (white/cyan/magenta)
- **Play buttons:** Circle, filled with category color, dark text/icon
- **Progress bar:** 4px track, filled with category color
- **Blog cards:** Glass surface, colored gradient thumbnail by category, avatar initials circle with cyan-magenta gradient
- **Footer:** 4-column grid, logo + descriptor, link columns, mono copyright

Hand-print measures smaller than a serif at the same px, so every size came up 1.5–2.5px and line-height came down. Equations are the one deliberate exception: `.nb-formula` and inline code are **monospace**, because a handwriting font that renders `1` like `l` is a liability in a product students revise arithmetic from. Accepted trade-off: a decorative face across the whole UI is harder to read than a workhorse sans for some users — the reference and the brief both call for it explicitly, and Patrick Hand is among the most legible hand-prints available, but a plain-text reading toggle is the obvious escape hatch if that ever bites. **A ruled line never strikes through writing.** The rules run the sheet's full height on a fixed 34px pitch while text flows freely, so lines were cutting straight through headings and labels. The `<select>` stays in the DOM as the single source of truth (every existing caller of `.value` and every `change` listener was left untouched); it is only replaced on screen. Margin doodles (triangle, E=mc², parabola, paper plane, molecule, DNA, flask, circuit, binary/flowchart, star, heart, "?") only appear ≥1180px, where the page grows real 116/132px gutters for them; below that they are removed rather than allowed to sit behind the text. **Answers carry 15 required sections** (Answer+Difficulty, Definition, Concepts & Formulas, Step-by-Step, Alternative Method, Important Notes, Common Mistakes, Quick Tip, Memory Trick, Real-Life Example, Teacher's Remark, Practice Question, Summary, Revision Box, and a Diagram on request); 12 of them render as their own tinted study card, while Concepts and Step-by-Step stay as body text because they *are* the answer, not a callout.
